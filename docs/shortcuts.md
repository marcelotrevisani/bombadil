# Keyboard shortcuts

On macOS, use ++cmd++ where this page says ++ctrl++.

| Keys | Action |
|---|---|
| ++ctrl+n++ | Add a project |
| ++ctrl+enter++ | Sync the selected project |
| ++ctrl+t++ | Open a terminal for the selected project |
| ++f5++ | Re-read the selected project from disk |
| ++ctrl+f++ | Filter the packages |
| ++ctrl+b++ | Collapse or expand the sidebar |
| ++esc++ | Close whatever is on top: a dialog, a menu or Settings |

**Help › Keyboard shortcuts** shows the same list inside the app.
