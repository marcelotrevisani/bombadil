# Tray Menu Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:executing-plans. Steps use `- [ ]`.

**Goal:** X hides to the tray (switchable); the tray menu lists projects and environments with Open terminal / Open in PyCharm; Show via activate/double-click.

**Architecture:** Pure `tray::menu_model` builds a snapshot from `Config` + sidebar entries; the `lib.rs` update wrapper pushes it to the tray when it changes. Menu presses come back as id-carrying `TrayCommand`s that `update` resolves and runs through the existing open paths with a cloned, re-pointed project.

**Tech Stack:** Rust, iced 0.14, ksni 0.3.6 (Linux), tray-icon 0.24.2 (macOS/Windows).

**Spec:** `docs/superpowers/specs/2026-10-15-tray-menu-design.md`

## Global Constraints
- No commits (user's standing instruction).
- Verification: `cargo fmt --all --check && cargo clippy --workspace --all-targets -- -D warnings -A clippy::chunks_exact_to_as_chunks && cargo test --workspace`.
- Never hide without a running tray (`window_action` guard stays, with its test).
- macOS/Windows paths compiled only; say so.

## Review Focus
1. A menu built before a project/environment was removed must do nothing when pressed (ids, not positions).
2. Opening from the tray must not change the saved config or the active environment.
3. With `close_to_tray` off, or no tray, the X quits — and the window size is saved on that quit.
4. A hidden window then Quit from the tray still saves the last size.
5. The menu refreshes after add/remove/rename/new env/probe — no stale labels.

### Task 1: Close routing + switch
Core `Settings.close_to_tray` (default true, serde default fn) + fixture; `Message::CloseRequested`; `close_requests()` → `CloseRequested`; Preferences Appearance choice pair; tests: default true on old config, routing on/off, persists.

### Task 2: Menu model + commands
`TrayProject`/`TrayEnvironment`/`menu_model` in tray.rs (tests); `TrayCommand::OpenTerminal/OpenPycharm{project, environment}`; update handler resolving ids, cloning with `active` set; tests: unknown ids ignored, config unchanged, the terminal command targets the chosen env.

### Task 3: Linux menu + push
ksni `Menu.projects`, `menu()` tree (test labels/nesting via a pure `menu_items(&[TrayProject]) -> Vec<Item>` description), `Tray::set_menu`; `App.tray_menu`; lib.rs update wrapper with `Rc<Option<Tray>>`.

### Task 4: macOS/Windows
`tray-icon` rebuild in `set_menu`, id map behind `Mutex`, DoubleClick → Show; compile check for those targets if the toolchain has them, else ledger that it was not compiled locally.
